# ADR 005. Стилизация: styled-components без дизайн-системы

Статус: Принято · 2026-09-18

## Контекст

Задание: styled-components — плюс; UI-библиотеки запрещены; «никакого inline-CSS»; анимация раскрытия дерева
через height transition; fade-подсветка обновлённых ячеек; уважение `prefers-reduced-motion`. Макет
(`task/design.drawio.xml`) — один экран: шапка (название, поиск, индикатор соединения), таблица слева,
дерево справа, у каждой панели свой скролл; на узком экране — одна панель и переключатель в шапке.

## Решение

- **styled-components** + `ThemeProvider`. Тема — типизированный объект токенов (`shared/config/theme`;
  лежит в `shared`, а не в `app`, потому что токены нужны всем слоям, а `shared` не имеет права
  импортировать `app`): палитра,
  семантические цвета (`perf.low/mid/high`, `status.ok/warn/error`, `flash`), шкала отступов, радиусы,
  типографика, тайминги, брейкпоинты (`split: 1280px`). `DefaultTheme` расширяется через declaration merging.
  Никакой «дизайн-системы»: только токены и несколько примитивов в `shared/ui` (Button, PerformanceBar,
  Tooltip, Spinner, Skeleton, StateMessage, VisuallyHidden).
- **Запрет inline-CSS технически:** правило ядра ESLint `no-restricted-syntax` с селектором
  `JSXAttribute[name.name='style']` — ловит и DOM-элементы, и компоненты, не требует `eslint-plugin-react`
  (который не поддерживает ESLint 10, см. ADR 001).
- **Динамика без `style`:**
  - конечные варианты — transient-пропсы (`$tone: 'low' | 'mid' | 'high'`, `$active`) или `data-*`/`aria-*`
    селекторы (`&[aria-expanded='true']`, `&[aria-selected='true']`) — состояние и так есть в разметке ради a11y;
  - отступ уровня дерева — за счёт вложенности `ul[role=group]` с `padding-inline-start`, без вычислений в JS;
  - **ширина заливки `PerformanceBar`** — единственное разрешённое исключение из запрета интерполяций
    непрерывными числами: transient-проп `$pct` (целое 0–100) и `transform: scaleX($pct / 100)`. Множество
    порождаемых классов ограничено 101 штукой по одной декларации в каждом; альтернативы — либо `style`,
    либо огрубление значения — хуже;
  - **высота раскрытия** — `display: grid; grid-template-rows: 0fr ↔ 1fr`, у внутреннего блока обязательны
    `min-height: 0` **и** `overflow: hidden` (grid-элемент по умолчанию `min-height: auto` и не сжимается
    ниже min-content — без этого приём молча не работает), а padding/margin/border у анимируемой обёртки
    должны быть нулевыми, иначе в свёрнутом состоянии остаётся видимая полоска;
  - **`inert` ставится синхронно из состояния**, а не по `transitionend`: это событие не приходит при
    `prefers-reduced-motion`, во вложенной уже свёрнутой ветке и в jsdom — иначе скрытые узлы навсегда
    остаются фокусируемыми и в дереве доступности. `visibility: hidden` вешает CSS по
    `[aria-expanded='false'] > ul`;
  - **массовое раскрытие** (`Развернуть все` / `Свернуть все`) выполняется без анимации: на корне дерева на
    один кадр ставится `data-animate="off"`, и хелпер `motion` под этим атрибутом отключает переходы. Иначе
    десятки вложенных анимируемых grid-контейнеров пересчитывают layout каждый кадр, причём внешние
    анимируются к цели, которая сама ещё меняется;
  - **fade обновлённой ячейки** — `@keyframes` (фон `flash → transparent`, 1.5 с) **без размонтирования**:
    хук `useFlash(value)` хранит предыдущее значение и фазу `'a' | 'b' | null` (старт — `null`), меняет фазу
    только когда значение действительно изменилось, а ячейка рендерит `data-flash`; в CSS объявлены два
    одинаковых `@keyframes` под разными именами, их чередование и перезапускает анимацию.
    Перезапуск через `key` не годится: смена ключа **монтирует** элемент, а маунт сам по себе запускает
    CSS-анимацию — вспыхивало бы всё при первой загрузке, при переключении «Дерево/Таблица», при пересечении
    1280px и у строк, вернувшихся после фильтра; вдобавок размонтирование уносило бы фокус строки.
    Сравнивается **отрисованное значение**, а не ссылка на объект: патч `performance` создаёт новый
    `Aggregate` у всех предков, и «Бюджет суммарный» мигал бы с неизменившимся числом.
- **Reduced motion:** один хелпер `motion` в теме оборачивает transition/animation в
  `@media (prefers-reduced-motion: no-preference)`; по умолчанию анимаций нет. Следствие, принятое
  осознанно: при `reduce` раскрытие мгновенное, а подсветки обновлений нет вовсе — единственный её носитель
  это анимация. Логика `useFlash` при этом не отключается (состояние считается всегда), гасится только
  визуальный слой.
- **Performance-индикатор (`PerformanceBar`):** по макету это дорожка с заливкой по значению плюс число
  рядом, одинаковая в дереве и в таблице. Разметка — `role="meter"` с `aria-valuenow`/`aria-valuemin`/
  `aria-valuemax`/`aria-valuetext`. Пороги `< 50` — low, `50–74` — mid, `≥ 75` — high (константы в
  `entities/org`); цвет всегда сопровождается числом; палитра проверяется на контраст.
- **Тултип** висит на индикаторе эффективности **узла дерева** (так в макете) и показывает собственный
  бюджет узла и время `updatedAt` — это единственное место, где поле `updatedAt` из контракта видно в UI.
- **Подсветка совпадений поиска** — `<mark>` внутри имени, в дереве и в таблице; разбиение имени на части
  делает чистая функция `splitByMatch`.
- **Заголовки сортировки** — `user-select: none`, иначе двойной клик выделяет текст заголовка.
- **Layout:** CSS grid; `≥ 1280px` — split-view (таблица | дерево), ниже — одна панель + переключатель
  «Дерево / Таблица» в шапке. Панели скроллятся внутри себя, страница — нет.
- Иконки — `lucide-react`, именованные импорты (tree-shaking); это не UI-библиотека, а набор SVG.

## Альтернативы

- **CSS Modules / vanilla-extract.** Нулевой рантайм и лучше для бюджета бандла, но задание прямо называет
  styled-components плюсом; ~13 КБ gzip укладываются в лимит.
- **Измерять `scrollHeight` и задавать высоту через `style`.** Классический способ, но это inline-CSS и
  лишние layout-чтения. `interpolate-size`/`calc-size()` — ещё не во всех браузерах.
- **CSS-переменная `--depth` через `style`.** Тот же inline-CSS.
- **Пропс-интерполяции с произвольными числами** (`$indent={depth * 20}`) — плодят неограниченное число
  классов и размывают токены. Ограниченный случай (`$pct`, 0–100) разрешён явно, см. выше.
- **Подсветка таймером в состоянии компонента.** Лишние ререндеры и очистка таймеров; CSS-анимация дешевле.

## Последствия

- Состояние компонентов отражается в ARIA/`data`-атрибутах, а стили подписываются на них — один источник
  правды для доступности и внешнего вида.
- Рантайм styled-components входит в бандл; следим через `npm run size`. Babel/SWC-плагин для displayName —
  только в dev.
- Анимация `grid-template-rows` поддерживается в Chrome 107+, Safari 16+, Firefox; где нет — раскрытие
  мгновенное, функциональность не страдает. В README одна строка о том, почему это и есть требуемый
  «height transition».
- jsdom не шлёт `transitionend`/`animationend` и не реализует `inert` — поэтому ни один тест не ждёт событий
  анимации, а состояния (`inert`, `data-flash`) проверяются как атрибуты.
- Стили, зависящие от пропсов, держим вне горячих путей (строки таблицы используют атрибутные селекторы,
  а не интерполяции), чтобы патчи не порождали генерацию новых классов.
